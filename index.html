DMS User Manual

Quick reference for using the Corporate DMS portal.

1. Dashboard

Use the dashboard to open Company Records, Project Documents, pending approvals and recent uploads.

2. Upload Documents

Select the document area, confirm the prefilled folder path, enter document metadata, attach the file and submit for approval.

3. Folder Library

Browse the left folder structure, open document details, preview files, share links, download documents or add documents to Bookmark.

4. Approvals

Review assigned documents, preview metadata, then approve or take action based on the approval workflow.

5. Settings

Admins can manage project creation, access, workflows, folder structure, departments and Settings visibility.
